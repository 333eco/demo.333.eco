One short link for everything you share

A B-Link is the address of something shared from a HeartBank® app: a letter, a shop, a signed file. It opens the real thing, on our own sites.

It only goes to our own sites

A B-Link can never point anywhere else. If it starts with B.333.eco, it leads to a HeartBank® app.

We count opens, never people

Each link keeps one number: how many times it was opened. We never keep who opened it, or from where.

A link never changes

Once made, a link points to the same place for good. It never runs out, and its code is never used again.

Anyone can check that a link was never changed. The log is public, and it lists no one's private links.

HeartBank® is a data bank of gratitude. It is not a chartered bank or financial institution; it does not provide banking services, hold deposits, or extend credit. Nothing is paid through B-Link.

Visits to this page are counted without cookies. Links themselves carry no tracker.
